## How to use this charter

- Read this page first, then the sections in order: context (01), product (02 to 05), structure (06), visual intent (07), design (08 to 14).
- Copy follows `05-voice-and-wording`: its tone, its vocabulary and its examples.
- Missing facts are written `[to provide: what]`. Nothing is invented: no names, figures, prices, reviews or awards.
- Every value comes from the tokens. A page never holds a raw colour, size, radius, duration or easing.
- Components are HTML and CSS. Their classes start with `ds-` in `components/bundle.css`; states use `is-hover`, `is-focus` and `is-active` in previews. Each component's README says what it is for and what the page provides.
