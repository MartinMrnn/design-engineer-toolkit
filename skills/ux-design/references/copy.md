# Writing the copy

## Voice
- Write in the client's trade voice: the words their customers use, not marketing vocabulary.
- One idea per sentence. Short paragraphs. Verbs rather than nouns.
- Headlines say something concrete: what, for whom, where, how. "Family law in Lyon, from the first meeting to the judgement" beats "Your trusted partner".

## The competitor test
Read every headline and call to action and ask: could a competitor publish this unchanged? If yes, rewrite it with something only this client can say: a fact, a place, a method, a number, a name. If you do not have that fact, write `[to provide: …]` rather than a vague sentence.

## Never invent
Names, figures, prices, dates, addresses, awards, reviews, quotes, team members, client logos: if neither the brief nor the user gave it, write `[to provide: what]`. A visible placeholder is honest; an invented fact in a mockup sent to a client is a liability.

## Avoid
- Empty superlatives: "best-in-class", "cutting-edge", "seamless", "elevate", "unlock", "world-class".
- Generic calls to action when a precise one exists: "Book a first call" beats "Get started".
- Placeholder text such as lorem ipsum, in any language.
- Exclamation marks in interface copy.

## Calls to action
- Name the action and its result: "See the menu", "Book a table for tonight".
- One primary action per screen. Secondary actions look secondary.

## Language
The site's copy is in the language set in the project `CLAUDE.md`, whatever language the user speaks to the studio.
