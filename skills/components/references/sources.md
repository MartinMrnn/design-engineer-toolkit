# Sources

Every source this skill and `components.js` rest on, with its link and its licence or status.

**What was copied: nothing.** Every text and code sample here is written in our own words. Where a licence forbids adaptation, or no licence could be found, only the principle is cited. Each idea is credited to the author who wrote it: "a role is a promise" and the key maps are the APG's; navigation that is not a menu, the card's stretched heading link, toggletips and "never change the label and the state together" are Pickering's; the focus indicator's area and adjacent colours, and the button that carries its own name, are Soueidan's; the curated libraries and the worst-case data are Kowalski's; the state carried in place with a separate status region is Hairline UI's.

**Not followed, on purpose.** Freiberg draws focus rings with `box-shadow`, because outlines used to ignore the radius; outlines follow it since Safari 16.4, survive forced colours, and the user chose a drawn outline on a live demo against a box-shadow ring and the browser default. Vercel keeps the original label on a loading button; the user chose Hairline UI's label that changes in place (`motion choreography-7`), announced by a status region. Krehel prefers the browser's own ring; the studio draws it from `--ring`, so its contrast is designed and measured.

**How licences were checked, on 2026-11-28.** Software licences were read from each repository through the GitHub API. Other licences were read on the source's own page.

## Standards
- **W3C** · WCAG 2.2, SC 1.3.1, 1.4.11, 1.4.13, 2.4.1, 2.5.3, 2.5.7 and 4.1.2, with their Understanding pages · https://www.w3.org/TR/WCAG22/ · Licence: W3C Document License (2023). Criteria are cited by number and stated in our own words.
- **APG** · W3C Web Accessibility Initiative, WAI-ARIA Authoring Practices Guide: "Read me first", the patterns (dialog, disclosure, menu button, menubar, tabs, combobox, listbox, radio group, switch, tooltip), "Developing a keyboard interface" · https://www.w3.org/WAI/ARIA/apg/ · Licence: W3C Document License for the prose (www.w3.org/WAI/about/using-wai-material: no derivative works); the repository `w3c/aria-practices` states the W3C Software and Document License. "No ARIA is better than bad ARIA", a role as a promise of keyboard behaviour, focus placement in a dialog, automatic or manual tab activation, roving tabindex and `aria-activedescendant`, `disabled` or `aria-disabled` for discoverability, focus never lost; principles cited.

## Practice
- **Freiberg** · Rauno Freiberg, Web Interface Guidelines, Interactivity, Accessibility and Touch sections · https://interfaces.rauno.me/ · Licence: none shown; the repository `raunofreiberg/interfaces` has no licence. A label click focuses its input, Enter submits through a form, toggles take effect at once, no dead gaps between list items, decorative layers without pointer events, no tooltip on a disabled button, tooltips never interactive, dropdowns open on press, a prediction cone for nested menus, icon-only controls named, input decorations that focus the input; principles cited.
- **Pickering** · Heydon Pickering, Inclusive Components: "Toggle Buttons", "Menus & Menu Buttons", "Tooltips & Toggletips", "Cards", "Notifications", "Collapsible Sections", "Tabbed Interfaces" · https://inclusive-components.design/ · Licence: none shown on the site; a paid book exists. Navigation as lists of links without ARIA menu roles, `aria-expanded` on the button, a fixed label with `aria-pressed` or a changing label but never both, toggletips announced through a live region, the heading link's `::after` over the card, live regions present before their content, tabs only where expected; principles cited.
- **Soueidan** · Sara Soueidan, "A guide to designing accessible, WCAG-conformant focus indicators" (2021, updated 2023), "Accessible icon buttons" (2019), "Inclusively hiding and styling checkboxes and radio buttons" (2020) · https://www.sarasoueidan.com/blog/ · Licence: © Sara Soueidan, all rights reserved. Contrast against adjacent colours, the indicator's area, outlines that survive forced colours, a two-tone ring for any ground, the name carried by the button rather than its icon, a custom control that keeps the real input in place; principles cited.
- **Kowalski** · Emil Kowalski, `pick-ui-library`, `emil-design-eng` and `break-ui` skills · https://github.com/emilkowalski/skills · Licence: MIT. The curated libraries (Base UI for primitives, Sonner, Vaul, cmdk), a hand-built dropdown replaced by a primitive, origin-aware popovers, tooltips without delay once one is open, edge cases handled invisibly, the worst realistic data fed through the real boundary and reported before fixing; principles cited.
- **Krehel accessibility** · Jakub Krehel, `better-accessibility` skill and its references (focus and keyboard, hit areas, semantics and ARIA, screen readers, forms) · https://github.com/jakubkrehel/skills · Licence: MIT. Criteria before conventions, native first, `disabled` and `aria-disabled`, `:focus-visible` and forced colours, roving tabindex, `<dialog>` with `showModal()` or `inert`, focus after a route change, hit areas grown by a pseudo-element on the label or button, decorative layers without pointer events, empty live regions first, label in name, a review in two walks (keyboard, then screen reader); principles cited.
- **Vercel** · Vercel, Web Interface Guidelines, Interactions and Content sections · https://github.com/vercel-labs/web-interface-guidelines · Licence: MIT. Keyboard everywhere after the APG, `:focus-within` for groups, hit targets matching visuals, loading delays and minimum durations, an ellipsis on follow-up actions and running states, `touch-action: manipulation`, no dead zones, links that are links, polite announcements, skip link and headings; principles cited.
- **Hairline** · Hairline UI components, by Harvansh: Status button, Cookie consent, Variant pick · https://hairlineui.com/ · Licence: components MIT (hairlineui.com/license, read on 2026-11-28); templates and Pro blocks under a separate commercial licence, not used. A control that carries idle, working, done and failed in place, a visually hidden status region outside it, focus kept while working, no animation library; principles cited.
- **shadcn** · shadcn/ui theme tokens · https://github.com/shadcn-ui/ui · Licence: MIT. Token names used (`--ring`, `--radius`, `--primary`).
- **Studio** · this project's own method, its interview with the user, its clickable demo and its measure of 23 home pages · https://github.com/MartinMrnn/design-engineer-toolkit · Licence: MIT.
