# Sources

Every source this skill and `motion.js` rest on, with its link and its licence or status.

**What was copied: nothing.** Every text and code sample here is written in our own words. Where a licence forbids adaptation, or no licence could be found, only the principle is cited. Each idea is credited to the author who wrote it: the easing tree and "never animate keyboard actions" are Kowalski's; "springs for things with weight" is Salaja's; springs drawn with `linear()` are Comeau's; "frequent, low-novelty actions animate less" is Freiberg's; state changes carried in place and morphing labels are Hairline UI's.

**Not followed, on purpose.** Salaja and Comeau put ease-in on exits; the user compared it with ease-out on a live demo and chose ease-out for both. Kowalski and Krehel allow dialogs and drawers up to 450–500 ms; the user chose 300 ms for the whole interface.

**How licences were checked, on 2026-11-27.** Software licences were read from each repository through the GitHub API. Other licences were read on the source's own page.

## Standards
- **W3C** · WCAG 2.2, SC 2.2.2, 2.3.1 and 2.3.3, with their Understanding pages · https://www.w3.org/TR/WCAG22/ · Licence: W3C Document License (2023). Criteria are cited by number and stated in our own words; 2.3.3 (AAA) is cited as the ground of the studio's own bar.

## Practice
- **Kowalski** · Emil Kowalski, `emil-design-eng`, `animate` and `choreograph` skills · https://github.com/emilkowalski/skills · Licence: MIT. The decision framework in order (frequency, keyboard, purpose, easing, duration), the easing tree and its curves, durations by element, springs and interruption, scale and origin, transitions over keyframes, blur to bridge a crossfade, reduced motion as fewer and gentler, hover gating, exits shorter, choreography (one entrance per container, roles, relationships, stagger, never blocking); principles cited.
- **Krehel motion** · Jakub Krehel, `better-motion` skill and `better-accessibility/motion-and-zoom.md` · https://github.com/jakubkrehel/skills · Licence: MIT. Frequency decides, menus that animate only on close, motion never the only cue, durations by size and shorter exits, springs by duration with bounce 0, scale by size, origin toward the trigger, travel distances, one `layoutId` per pair, measured height, theme switch without transitions, `will-change` only after a seen jump, what reduced motion disables, replaces and keeps; principles cited.
- **Salaja** · Raphael Salaja, `userinterface-wiki`, animation rules and "To Spring or Not To Spring" · https://github.com/raphaelsalaja/userinterface-wiki · Licence: MIT. Timing under 300 ms, no animation on keyboard navigation or high-frequency actions, context menus animated only on exit, shorten before changing the curve, linear only for progress, springs for gestures and interruption, one focal point, container bounds with two elements and a `ResizeObserver`; principles cited.
- **Salaja timing** · Raphael Salaja, "A Note on Timing" (19 January 2026) · https://raphaelsalaja.com/library/a-note-on-timing · Licence: none shown. The more often seen, the shorter; starting durations by element; exits about half to a little more than the entry; nothing under about 100 ms if it must be seen moving; counting frames to time a reference; principles cited.
- **Salaja spring** · Raphael Salaja, "When to Use a Spring" (21 October 2025) · https://raphaelsalaja.com/library/when-to-use-a-spring · Licence: none shown. Springs for things with weight, the weight test, eases for opacity, colour and blur, springs set by duration and bounce, low bounces for interface; principles cited.
- **Freiberg** · Rauno Freiberg, Web Interface Guidelines, Animation and Touch sections · https://interfaces.rauno.me/ · Licence: none shown. No transitions on a theme switch, frequent low-novelty actions without extra animation, context menus animated only on exit, loops paused off screen, scale proportional to the trigger, hover gated on touch screens; principles cited. Its 200 ms ceiling is noted, the studio keeps 300 ms.
- **Freiberg interaction** · Rauno Freiberg, "Invisible Details of Interaction Design" (July 2023) · https://rauno.me/craft/interaction-design · Licence: none shown. Motion from real-world metaphors, momentum kept, interruptible animations, origin matching the source, less motion on frequent and keyboard actions; principles cited.
- **Freiberg depth** · Rauno Freiberg, "Designing Depth" (July 2024) · https://rauno.me/craft/depth · Licence: none shown. Choreography as deliberate ordering, layers sequenced so they do not collide, what is nearest the trigger moves first, slight staggers like a flock; principles cited.
- **Comeau springs** · Josh W. Comeau, "Springs and Bounces in Native CSS" · https://www.joshwcomeau.com/animation/linear-timing-function/ · Licence: © Joshua Comeau, all rights reserved. Springs drawn with `linear()`, generated points, a token with an `@supports` fallback, the limits of a time-based spring; principles cited.
- **Comeau reduced motion** · Josh W. Comeau, "Accessible Animations in React with prefers-reduced-motion" · https://www.joshwcomeau.com/react/prefers-reduced-motion/ · Licence: © Joshua Comeau, all rights reserved. Motion as opt-in, no global reset, listening in script, a still first render, the vestibular figure from vestibular.org; principles cited.
- **Comeau transitions** · Josh W. Comeau, "An Interactive Guide to CSS Transitions" · https://www.joshwcomeau.com/animation/css-transitions/ · Licence: © Joshua Comeau, all rights reserved. Name the property, never `all`; transform and opacity; different transitions in and out; principles cited.
- **Hairline** · Hairline UI components, by Harvansh · https://hairlineui.com/ · Licence: components MIT (hairlineui.com/license, read on 2026-11-27); templates under a separate commercial licence, not used. States carried in place, labels that morph, the moment of success marked where it happened, a state change without motion under reduced motion; principles cited.
- **Tailwind** · Tailwind CSS theme, `--ease-*`, `--animate-*`, `--default-transition-duration` · https://github.com/tailwindlabs/tailwindcss · Licence: MIT. Token names used.
- **Studio** · this project's own method, its interview with the user, its live demos and its measure of 23 home pages · https://github.com/MartinMrnn/design-engineer-toolkit · Licence: MIT.
