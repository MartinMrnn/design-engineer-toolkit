# Sources

Every source this skill and `type.js` rest on, with its link and its licence or status.

**What was copied: nothing.** Every text here is written in our own words. Where a licence forbids adaptation or none could be found, only the principle is cited.

**How licences were checked, on 2026-11-23 and 24.** Software licences were read from each repository through the GitHub API. Other licences were read on the source's own page. Where a page showed none, the entry says so.

## Standards
- **W3C** · WCAG 2.2, SC 1.4.4, 1.4.5, 1.4.8, 1.4.12, and failure F94 on viewport units · https://www.w3.org/TR/WCAG22/ · Licence: W3C Document License (2023). Criteria are cited by number and stated in our own words.

## Typography practice
- **Krehel typography** · Jakub Krehel, `better-typography` skill · https://github.com/jakubkrehel/skills · Licence: MIT. Roles, leading, tracking, weights, wrapping, loading; principles cited.
- **Krehel** · Jakub Krehel, `make-interfaces-feel-better`, `typography.md` · https://github.com/jakubkrehel/make-interfaces-feel-better · Licence: MIT. `balance` and `pretty`; principle cited.
- **Salaja** · Raphael Salaja, `userinterface-wiki`, the `type-*` rules · https://github.com/raphaelsalaja/userinterface-wiki · Licence: MIT. Figures, synthesis, `font-display`, wrapping; principles cited.
- **Kowalski** · Emil Kowalski, `apple-design` skill, section 15 · https://github.com/emilkowalski/skills · Licence: MIT. Tracking and leading by size; principle cited.
- **Kowalski Agents** · Emil Kowalski, "Agents with Taste" · https://emilkowal.ski/ui/agents-with-taste · Licence: none shown. Fallback metrics; principle cited.
- **Freiberg** · Rauno Freiberg, Web Interface Guidelines · https://interfaces.rauno.me/ · Licence: none found, on the page or its repository. Principles cited.
- **Coursey rem** · Paco Coursey, "px vs rem in font-size" · https://paco.me/writing/px-vs-rem · Licence: none shown. Principle cited.
- **Vercel** · Vercel, Web Interface Guidelines · https://github.com/vercel-labs/web-interface-guidelines · Licence: MIT. Punctuation; principle cited.
- **Utopia** · James Gilyead & Trys Mudford, the fluid type calculator · https://utopia.fyi/type/calculator/ · Licence: none shown. The method is cited, the linear formula is general mathematics.
- **Barvian 2023** · Maxwell Barvian, "Addressing Accessibility Concerns With Using Fluid Type", *Smashing Magazine* · https://www.smashingmagazine.com/2023/11/addressing-accessibility-concerns-fluid-type/ · Licence: none shown. The 2.5 ratio is cited.
- **shadcn** · shadcn/ui, `--font-sans`, `--font-heading`, `--font-mono` · https://github.com/shadcn-ui/ui · Licence: MIT. Token names used.
- **Tailwind** · Tailwind CSS theme, `--text-*` and its line-height, weight and spacing variants · https://github.com/tailwindlabs/tailwindcss · Licence: MIT. Token names used.
- **Puckett** · Josh Puckett, the Allo typeface, read as a reference · https://allo.joshpuckett.me/ · Licence: OFL-1.1 for the typeface. Nothing taken from it; its site is one of the pages measured.
- **Studio** · this project's own method, its interview with the user and its measure of 17 pages · https://github.com/MartinMrnn/design-engineer-toolkit · Licence: MIT.
