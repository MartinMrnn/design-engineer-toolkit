# Where to look for references

Use these only when the user asks for references, or when the moodboard has a gap (no type reference, no motion reference…). The user's moodboard always comes first.

| Gallery | Good for |
|---|---|
| awwwards.com | Ambitious sites, motion and interaction |
| godly.website | Contemporary web design, with short motion previews |
| siteinspire.com | Clean, editorial and portfolio sites, filtered by type |
| land-book.com | Landing pages, by industry |
| minimal.gallery | Restrained, typographic sites |
| httpster.net | Bold and unusual sites |
| fontsinuse.com | Typefaces in real projects |
| typewolf.com | Type pairings and font recommendations |

## Rules
- Look for principles (a grid idea, a type contrast, a colour logic), never for a layout to copy.
- Bring back 3 to 6 references, each with a capture and one line on what it brings.
- Add them to `design/inspiration/inspiration.md`, marked "proposed by the art director", and ask the user to keep or drop each one.
